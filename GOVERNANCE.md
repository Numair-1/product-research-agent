# Milestone II governance note — Product Research Agent

**Accountable: Numair Abdulle.** Numair owns the public deployment, manages the provider keys and quotas, and is responsible for responding to reports of misuse or misleading results.

**Data and storage.** A visitor enters a product name (up to 200 characters). Groq receives that input and the run’s previous tool arguments and observations. Tavily receives search queries and returns titles, URLs, and snippets. An approved source website receives a GET request from the app, without API keys or cookies. The app holds pending work, retrieved evidence, citations, decisions, and the final report in server memory for that Streamlit session. It has no application database or shared visitor history. Downloading the JSON trace saves a copy on the visitor’s device. The repository’s separate evaluation ledger records benchmark outcomes and counts, not public sessions. Hosting and API providers may keep their own logs; the app does not control their retention.

**Public access and approval.** Anyone with the public link can start research, consume the app’s API quota, inspect cited evidence, and download their own trace. Clicking **Research Product** starts Groq and Tavily calls without another prompt. When Groq proposes `read_webpage` for an exact URL already returned by Tavily, the loop pauses **after tool selection and before DNS lookup or HTTP fetch**. The screen names `read_webpage` and displays its only argument as JSON: `{"url": "<full Tavily URL>"}`, including any query string. **Approve this read** permits one attempt for that URL; **Skip this read** continues without fetching it. Each subsequent read requires a new decision.

Approval cannot override the public-address, redirect, timeout, or size checks. Visitors cannot use the interface to retrieve private network pages, view keys or another session’s trace, alter websites, purchase products, or publish changes. Credentials stay server-side in environment variables, a local ignored `.env`, or Streamlit secrets. Citations identify retrieved evidence; visitors should verify consequential claims at the source.
